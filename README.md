# AUTOLOOP MVP 0.2

Prototype fonctionnel local, sans serveur.

## Fonctionnalités
- Catalogue de pièces
- Recherche
- Panier
- Création de commande simulée
- Profil vendeur local
- Tableau de bord
- Données conservées dans le navigateur (localStorage)

## Utilisation
Ouvrir `index.html` dans Safari/Chrome/Edge.

## Important
Ce n'est pas encore une marketplace de production :
- pas de vrai compte utilisateur
- pas de vraie base de données
- pas de paiement
- pas de reversement vendeur
- pas de livraison connectée
- pas de validation juridique
- les commandes sont simulées

## Étape suivante
Passer sur une architecture serveur avec base de données, authentification, catalogue vendeur et paiement marketplace.
